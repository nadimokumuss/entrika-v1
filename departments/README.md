# Entrika Departmanlar

Bu klasörde proje departmanlarının talimatları bulunur.

## Departmanlar

| Departman | Dosya | Açıklama |
|-----------|-------|----------|
| **UI/UX** | `ui-ux.md` | Tasarım, renk paleti, düzen, kullanıcı deneyimi |
| **Front-end** | `front-end.md` | React Native bileşenleri, ekranlar, navigasyon |
| **Back-end** | `back-end.md` | Supabase, edge functions, API |
| **Database** | `database.md` | SQL şemaları, triggerlar, migration |
| **DevOps** | `devops.md` | Vercel deploy, CI/CD, environment |
| **Testing** | `testing.md` | Test yazma, hata ayıklama |
| **Documentation** | `documentation.md` | Dokümantasyon, README, comments |

## Kullanım

**Örnek komutlar:**
- "UI departmanı, feed ekranını yeniden tasarla"
- "Front-end departmanı, login ekranına hatırlatma ekle"
- "Database departmanı, profiles tablosuna age alanı ekle"
- "DevOps departmanı, Vercel deploy ayarlarını kontrol et"

**Birden fazla departman:**
- "UI ve Front-end departmanları, yeni profil ekranını birlikte yapın"

## Notlar

- Her departman kendi dosyasındaki talimatlara uyar
- Departmanlar birbiriyle koordineli çalışır
- Çapraz departman görevlerinde iletişim önemlidir
