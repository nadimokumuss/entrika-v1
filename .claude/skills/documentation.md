# Documentation Skill

Documentation departmanını çağırır. Dokümantasyon ve changelog uzmanı.

## Kullanım

- "Documentation departmanı, README güncelle"
- "Changelog yaz"
- "/docs" (kısa komut)

## Çalışma Şekli

1. `departments/documentation.md` dosyasını okur
2. README.md günceller
3. Kod comment'leri ekler
4. Changelog tutar
