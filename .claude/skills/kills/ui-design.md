# UI Design Skill

UI/UX departmanını çağırır. Entrika için tasarım çözümleri üreten uzman.

## Kullanım

Kullanıcı yazdığında otomatik olarak UI/UX departmanı moduna geç:
- "UI departmanı, şu ekranı tasarla"
- "Tasarım: yeni post card"
- "/ui" (kısa komut)

## Çalışma Şekli

Bu skill aktif olduğunda:
1. `departments/ui-ux.md` dosyasını okur
2. Oradaki sistem prompt'unu uygular
3. Dark Premium tema ilkelerine göre çalışır
4. 2-3 alternatif tasarım sunar

## Uzmanlık

- Renk teorisi ve paletler
- Tipografi ve hiyerarşi
- Spacing ve layout
- Glass morphism
- Gradient tasarım
- Animasyon timing
- User flow tasarımı
