# Front-end Skill

Front-end departmanını çağırır. React Native ekran ve bileşen geliştirme uzmanı.

## Kullanım

- "Front-end departmanı, login ekranı düzenle"

1. `departments/front-end.md` dosyasını okur

3. TypeScript kullanır
4. Platform kontrolleri (web/native) ekler
